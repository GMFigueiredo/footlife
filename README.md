# Football Career Simulator

An offline-first, moddable browser game about one footballer's life and career.

This repository will contain the game code, data packs, mods, tests, and design documentation. The game will prioritize a reactive world, decisive interactive match moments, and long-term career stories over complex graphics.

## Start here

- [Project documentation](docs/project-documentation.md) — vision, scope, architecture, and roadmap.
- `src/` — future game code.
- `data/` — built-in world and gameplay data.
- `mods/` — example and community-created content packs.
- `tests/` — automated tests for the simulation.

## Project status

Pre-production. The next deliverable is the prototype content specification: a small fictional country and league, eight clubs, player archetypes, and the first match scenarios.
